# Raw test data (Phases 5 and 6)

One folder per test day, named `YYYY-MM-DD_short-description`, holding the raw logger CSVs untouched and a `notes.md` with plate, paste mass, clamp setting and anything unusual.

- `predictions.csv`: CFD predictions committed before each test. The commit date shows the prediction came first.
- `plate_inspection.md`: measured pin diameters, flatness and tip contact for each printed plate

Raw files are never edited. Corrections happen in `08_analysis`.
